Program 3: Electricity Bill Generator
Python Code
units = int(input("Enter Units: "))

if units <= 100:
    bill = units * 1.5
elif units <= 200:
    bill = (100 * 1.5) + ((units - 100) * 2.5)
else:
    bill = (100 * 1.5) + (100 * 2.5) + ((units - 200) * 4)

print("Electricity Bill =", bill)
Sample Input
250
Sample Output
Electricity Bill = 600.0
